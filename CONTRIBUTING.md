# Contributing to `brand`

Voice and design are personal. This repo documents *my* discipline, not a general-purpose brand system. Contribution scope is narrow.

## What's welcome

- **Typo fixes / broken links:** always. Open a PR.
- **Factual corrections:** hex values, font-weight ranges, ANSI codes, SVG spec accuracy.
- **Missing OSS references:** if the CC BY 4.0 license attribution should point somewhere I've missed, tell me.

## What's not the right fit

- **Suggestions to change the palette, typography, or voice anchors.** Those decisions are made; they're the identity.
- **Requests to license the wordmark** for use in your work. The wordmark is personal identity, not shared brand.

## Voice + style

This repo follows its own [`identity.md`](identity.md) rules. See that file before opening a PR.
